# Финальный план развития проекта до уровня диссертации

Дата фиксации плана: 2026-02-18  
Плановый период: 2026-02-23 — 2026-05-17 (12 недель)

## 1) Общая цель
Построить и обосновать СППР для мониторинга и диагностики серверного оборудования, где система:
- прогнозирует риск отказа на горизонтах 24ч/7д/30д;
- учитывает неопределённость прогноза;
- выбирает действие по ожидаемой стоимости ошибок;
- даёт интерпретируемую рекомендацию для ИТ-службы.

## 2) Рамки работы (что включено и исключено)
Включено:
- прогноз риска отказа;
- decision layer (expected loss, cost-sensitive правила);
- персонализация риска по типу сервера и истории;
- объяснимые рекомендации.

Исключено:
- детекция аномалий как отдельный трек;
- правило «всё вне нормы = аномалия».

## 3) Базовые тезисы исследования
1. Для серверного мониторинга полезнее прогнозировать риск отказа на горизонтах 24ч/7д/30д, чем искать аномалии.
2. Решения должны приниматься по ожидаемой стоимости ошибок, а не по статическим порогам.
3. Учет неопределённости прогноза снижает риск неверных действий при шумных и неполных данных.
4. Объединение нескольких каналов телеметрии (SMART/IPMI/системные метрики) улучшает оценку риска.
5. Интерпретируемые рекомендации повышают применимость СППР в ИТ-службе.
6. Единый порог для всех серверов хуже, чем персонализированная оценка риска по типу сервера и истории.
7. Простая, но калиброванная и объяснимая модель практичнее, чем сложная непрозрачная.

## 5) Критерии готовности
1. Есть не только прогноз, но и формальный выбор действия по стоимости риска.
2. Есть калиброванные вероятности и оценка неопределённости.
3. Есть сравнение с пороговым подходом и доказанный практический выигрыш.
4. Есть интерпретируемые рекомендации для эксплуатации.
5. Есть воспроизводимый контур экспериментов и демонстрационные кейсы.
